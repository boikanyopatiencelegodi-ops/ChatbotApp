# ChatbotApp
## Description
This is a GUI-based Cybersecurity Awareness Chatbot built using C# and Windows Forms.

## Features
* **Task Assistant:** Users can add cybersecurity tasks to a simulated database.
* **Cybersecurity Quiz:** A 10-question game that tests the user's knowledge.
* **NLP Simulation:** Uses string manipulation to understand different phrasing.
* **Activity Log:** Records actions taken by the bot.
